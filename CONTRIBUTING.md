# Contributing

Contributions and improvements are welcome.

## Local setup

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Before submitting changes

- Keep the project dependency-free unless a dependency is clearly justified.
- Preserve keyboard accessibility and responsive behaviour.
- Test at desktop and mobile widths.
- Keep security policies in sync if editing both JavaScript and the Python companion.
- Do not commit generated local audit data.

## Suggested commit style

```text
feat: add new access policy
fix: correct mobile navigation
ui: improve authentication panel
docs: update architecture notes
```
